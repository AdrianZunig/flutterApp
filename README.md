# flutterApp
Aplicación móvil con AR (Realidad Aumentada).
El presente proyecto de residencia profesional tiene como finalidad el diseño y
desarrollo de una aplicación híbrida interactiva, la cual integra tecnología de
Realidad Aumentada (AR) como herramienta central. El objetivo principal es difundir
la riqueza cultural, histórica y natural de los 12 pueblos originarios de la Alcaldía de
Milpa Alta, facilitando recorridos virtuales por sitios de interés como museos,
parques, reservas y festividades tradicionales.
